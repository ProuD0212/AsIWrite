# 내가 쓰는 대로 (As I Write)

A 2D top-down narrative god-sandbox. You write the world into being through one chat box — and the **Wills (윌)** who live in it go on with their own will: they work, chat, gossip, fall out, comfort each other and keep diaries.

> 진행 상태: **개발 중 (Phase 1·2·3 코드 구현, AI 모델 실제 동작·Phase 3 테스트 진행 중)**. 아래 "구현 상태" 표에 실제로 동작하는 것만 적었습니다.

## 실행 방법

**더블클릭 실행:** Windows는 `실행.bat`, macOS는 `실행.command`(처음 한 번은 우클릭 → 열기). 처음 실행하면 필요한 파일을 자동으로 설치하고, 잠시 후 브라우저가 열립니다. 게임을 끝내려면 검은 창을 닫으세요. (Node.js LTS가 설치돼 있어야 합니다.)

직접 실행하려면:

```bash
npm install
npm run dev      # http://localhost:5173
# 또는
npm run build && npm run preview
```

API 키, 회원가입 없이 바로 실행됩니다. 이미지·오디오 파일은 하나도 없고, 그림은 전부 Canvas로 그리며 효과음은 Web Audio로 합성합니다.

## 조작

| 방법 | 내용 |
|---|---|
| 타이틀 입력창 | `빛이 있으라`, `시작`, `비 오는 현대 서울에 고양이 한 마리와 시작` → 시작 · `설정` · `불러오기` · `종료` (아래 힌트 단어는 클릭해도 됩니다) |
| 상단 채팅창 | `고양이를 좋아하는 샐러리맨 소환`, `갑자기 소나기가 내리게 해줘`, `세계관을 중세 판타지로 변경`, `박철수와 정하늘이 마주치게 해줘`, `김민수가 복권에 당첨됐다는 소문 퍼뜨려` … (❓ 도움말에 예시가 더 있어요) |
| 채팅 없이 | 왼쪽 도구 막대(소환·날씨·세계관·번개·만남·축복·선물·지우기·저장), 캐릭터/건물 클릭 → 인스펙터, 🔥 트렌드 패널 |
| 카메라 | 드래그 / WASD · 휠 / `+` `-` 확대 · `Space` 일시정지 · `1`~`5` 배속(1·2·3·5·10배) · `J` 밤 건너뛰기 · `X` 맵 편집(직선 길 깔기·테두리 끌어 크기 조절) · `Ctrl/⌘ Z` 되돌리기 · 우클릭 메뉴 · `F` 추적 · `Esc` 해제 |

채팅창으로 할 수 있는 모든 일은 GUI로도 할 수 있습니다. 둘 다 같은 `GameCommand`(JSON)를 만들어서 `Game.dispatch()` 하나로 처리합니다.

## 폴더 구조

```
src/
  engine/      시뮬레이션 (World, TileMap, SpatialGrid, 특성 해석, 소문, 저장)
  engine/render/  Canvas 렌더러 (지도, 6레이어 캐릭터, 조명·날씨)
  commands/    GameCommand 스키마, 자연어 규칙 파서, 타이틀 의도 분류
  presets/     기본 세계(텍스트), 무작위 특성/외형/애착 물건 생성기, 대사 템플릿
  ui/          React HUD (도구 막대, 인스펙터, 트렌드, 모달)
  audio/       Web Audio 효과음
```
