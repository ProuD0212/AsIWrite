# 내가 쓰는 대로 (As I Write)

문장으로 세상을 만드는 마을 시뮬레이션 게임입니다.
"고양이를 좋아하는 바리스타 소환", "중앙에 인도를 쭉 깔아줘", "광장에서 축제 열어 줘"처럼 쓰면 그대로 일어나고,
마을 사람들("윌")은 각자의 성격·기분·관계에 따라 대화하고, 일하고, 소문을 퍼뜨리고, 사랑에 빠집니다.

브라우저에서 돌아가며 서버나 회원가입이 필요 없습니다.

## 실행

**준비물**: [Node.js](https://nodejs.org) LTS(20 이상), Chrome 또는 Edge 최신 버전

| 운영체제 | 방법 |
|---|---|
| Windows | `start-windows.bat` 더블클릭 |
| macOS | `start-mac.command` 더블클릭 (처음 한 번은 우클릭 → 열기) |
| 직접 실행 | `npm install` 후 `npm run dev` → 표시되는 주소를 브라우저로 열기 |

처음 실행할 때 필요한 패키지를 자동으로 설치합니다. 끝낼 때는 타이틀 화면의 「종료」를 누르거나 실행 창을 닫으세요.

## AI 이야기꾼 (선택)

윌들의 대사를 성격과 관계에 맞게 자연스럽게 다시 써 주는 기능입니다. 게임에 처음 들어가면 고를 수 있고, 설정에서 언제든 바꿀 수 있습니다.

- **API 사용 (권장)** — Google Gemini 또는 Groq의 무료 API 키. 가볍고 문장이 가장 자연스럽습니다. 키 발급 페이지로 바로 연결해 줍니다. 키는 브라우저에만 저장되고 해당 서비스에만 전송됩니다.
- **내장 모델** — 브라우저 안에서 Gemma 4 E2B(그래픽 메모리 약 3.4GB) 또는 Qwen3.5 2B(약 2.2GB)를 돌립니다. 키는 필요 없지만 처음 한 번 수 GB를 내려받고, WebGPU를 지원하는 GPU가 필요합니다.
- **사용 안 함** — 기본 문장으로도 게임은 그대로 즐길 수 있습니다.

뜻 비교에는 한국어 문장 임베딩 모델(`jhgan/ko-sroberta-multitask`, 약 420MB)을 브라우저에서 사용합니다. 받지 못하면 글자 비교로 동작합니다.

## 조작

채팅창(Enter)에 문장을 쓰는 것만으로 모든 것을 할 수 있고, 같은 일을 왼쪽 도구 막대와 클릭으로도 할 수 있습니다. 게임 안에서 `?`를 누르면 전체 단축키 표가 나옵니다.

| 하는 일 | 마우스 · 키보드 | 노트북 터치패드 |
|---|---|---|
| 화면 이동 | 드래그, `W` `A` `S` `D` / 방향키 | 두 손가락으로 쓸기 |
| 확대 · 축소 | 휠, `=` `-` | 두 손가락 벌리기 · 오므리기 |
| 메뉴 | 우클릭 | `Ctrl`/`⌥`+클릭, 길게 누르기, `.` |
| 건물 회전 | 놓거나 옮기는 중 `R` | |
| 되돌리기 | `Ctrl`/`⌘`+`Z` | |

채팅 예시: `비 오는 날을 싫어하는 학생 소환` · `카페 하나 지어 줘` · `김민수와 이영희가 마주치게 해 줘` · `길가에 가로수 심어줘` · `한별에게 "요즘 어때?"` · `세계관을 중세 판타지로 바꿔`

## 다른 PC에서 접속 (선택)

설정의 「🌐 다른 PC에서 접속」에서 서버를 켜면, 같은 네트워크의 다른 PC가 표시된 주소로 접속할 수 있습니다. AI 계산은 기본적으로 서버를 연 PC가 맡습니다. 필요할 때만 켜 두세요.

## 구조

```
src/
  App.tsx            화면 흐름(타이틀 → 게임), AI 연결
  engine/            시뮬레이션 — World(상태·메인 업데이트), Game(조작·명령 실행), TileMap, 렌더러, 저장
  engine/world/      World의 나머지를 영역별로 — 행동 결정 · 일과 · 대화 · 의뢰 · 관계 · 연애 · 그룹 · 소문 · 사건 · 맵 편집
  commands/          문장 → 게임 명령 (규칙 해석 · 맵 문장 해석 · 모델 출력 검사)
  ai/                AI 이야기꾼, 문장 임베딩, API 연결, 배운 문장, 다른 PC 중계
  ui/                HUD, 인스펙터, 창들, 튜토리얼
  audio/             효과음, 배경 음악(Web Audio로 생성)
  presets/           기본 마을, 특성·이름·대사 목록
server/lanShare.ts   개발 서버 플러그인: 다른 PC 접속 · AI 중계 · 종료 버튼
tests/               헤드리스 시험 — npm test (브라우저 없이 실제 엔진으로 300여 개 검사)
```

이미지·음악 파일 없이 그림(픽셀 스프라이트)과 소리를 모두 코드로 만들어 냅니다.
